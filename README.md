# تطبيق أثر (Athar App)

تطبيق "أثر" هو تطبيق ويب تقدمي هجين (Hybrid PWA) يعمل كبرنامج معرفي وعبادي يومي. تم تصميمه ليكون سريعاً ويعمل بكفاءة عالية حتى في حالة انقطاع الإنترنت (Offline-First)، مع الحفاظ على التزامن السحابي عند توفر الاتصال عبر Supabase.

## فكرة التطبيق الهجين (Hybrid Concept)
يعمل التطبيق كنظام مزدوج (Dual-System):
1. **المسار الأول (Offline-First):** يعتمد على ملفات JSON المدمجة داخل التطبيق للمحتوى الثابت (المناسبات، التعقيبات، أعمال الأسبوع) لضمان عمل التطبيق بسرعة فائقة وبدون الحاجة للإنترنت.
2. **المسار الثاني (Online & Dynamic):** يعتمد على Supabase لجلب المحتوى الديناميكي وحفظ المفضلات، وإدارة جلسات المستخدمين المجهولين، وإرسال الإشعارات والملفات عبر دوال Supabase (Edge Functions) وبوت تيليغرام.

## تفاصيل دوال ومكونات الملفات الأساسية

### المكونات المشتركة
- **BottomNav:** شريط التنقل بين المسارات الأساسية للتطبيق.
- **ReaderView:** قارئ النصوص القابل للتخصيص (حجم الخط، الوضع الليلي، الإضافة للمفضلة).
- **PDFViewer:** واجهة مخصصة لعرض ملفات PDF مع خيار إرسالها فوراً إلى حساب المستخدم في تيليغرام عبر دوال Edge.

### إدارة الحالة والسياق
- **AppContext:** يجهز المحتوى اليومي (المناسبات والأعمال) بناءً على التاريخ الهجري وأيام الأسبوع، معتمداً على البيانات المحلية.
- **AuthContext:** يدير جلسة المستخدم. يقوم بتسجيل الدخول بشكل مجهول (Anonymous) فور فتح التطبيق، ويحتوي على دوال لربط الحساب مع تيليغرام لاحقاً.

### استراتيجية غياب الإنترنت (Offline Strategy)
- المحتوى النصي الأساسي مدمج في ملفات JSON، مما يتيح التصفح الدائم.
- يتم تخزين المفضلات محلياً باستخدام `localforage` (في IndexedDB)، وعند عودة الاتصال يتم مزامنتها مع Supabase.

### نظام الربط مع تيليغرام و Edge Functions
1. **دالة الربط (Handshake Function):** عندما يفتح المستخدم رابط الربط من التطبيق نحو بوت تيليغرام، يتم ربط الجلسة المجهولة (Anonymous Session) بمعرف تيليغرام الفعلي (telegram_user_id) الخاص به في Supabase.
2. **دالة إرسال الملفات (Delivery Function):** عند الضغط على "إرسال لتيليغرام" للملفات (مثل الـ PDF)، يتم استدعاء دالة `send-pdf` السحابية التي تتخاطب مع Telegram Bot API وترسل الملف مباشرة إلى المستخدم.
3. **دالة الإشعارات المجدولة (Cron Notifications):** دالة تعمل في الخلفية لإرسال الإشعارات اليومية (مثل حديث اليوم) عبر البوت للمشتركين النشطين.
